# Metrology basis and qualification limits

## What the instrument measures

Lasertec documents 13.5 nm actinic inspection for the ACTIS A150. EUV mask features are observed through their reflected optical field. Lasertec's programmed-contact examples show sensitivity both to absorber-edge changes on 80 nm contacts and to multilayer phase defects. Image intensity therefore contains information about pattern geometry, mask materials and optical conditions. The exact ACTIS model, recipe, illumination and export transfer function for this dataset were unspecified. Published instrument examples inform the tests without setting a numerical PSF or detector calibration. [Lasertec A150 specification](https://www.lasertec.co.jp/en/products/semiconductor/actis_a150.html) · [Miyai et al., actinic patterned-mask inspection, figures 9–12](https://spie.org/documents/Membership/BacusNewsletters/BACUS-Newsletter-January-2020.pdf)

Lasertec describes the trade-off between illumination uniformity and efficiency across a TDI field. Independently, measured changes in the transfer function of a TDI sensor under velocity mismatch motivate testing scan-direction blur. The eight acquisitions probe different TDI regions in this experiment. Changes in source conditions during acquisition are confounded with detector position. Neither each hole's maximum nor a repeated array's page mean provides an independent source monitor. [Lasertec EUV source workshop, slides 6–8](https://euvlitho.com/2024/S63.pdf) · [Li et al., TDI velocity mismatch and modulation transfer](https://doi.org/10.1364/AO.419457)

## Separating mask geometry from image formation

A local approximation to the observed image is an emitting aperture blurred by an effective intensity kernel, integrated over detector pixels and scaled by local contrast and background. This model approximates the features useful for fitting. EUV partial coherence, absorber phase, shadowing, focus and neighboring patterns can violate the linear intensity approximation. Published actinic contact-hole work used through-focus data, calibrated optical simulation and matched SEM measurements to relate aerial-image measurements to mask CD. An actinic focus experiment also showed image-placement shifts that depended on pitch. [Pandey et al., AIMS-based mask metrology](https://doi.org/10.1117/12.2688109) · [Raghunathan et al., through-focus pattern placement](https://doi.org/10.1116/1.4901876)

At 21 nm/pixel a 70 nm hole spans 3.33 native pixels. An opening that is wider and less blurred can resemble a different opening under another blur and gain. Shape identification can fail before center localization does. The model profiles directional blur across neighboring holes and tracks fits with similar residual but different CD. Circle, square and ellipse hypotheses compete using spatial-frequency evidence. Indeterminate shape, weak contrast and ill-conditioned size estimates receive explicit flags. An effective PSF inferred from the same array can still carry systematic bias. [NIST parametric uncertainty in optical dimensional measurements](https://www.nist.gov/publications/parametric-uncertainty-nanoscale-optical-dimensional-measurements)

| Method | Source of robustness | Failure to inspect |
|---|---|---|
| Local relative contour | Local dark level and contrast reduce sensitivity to an affine intensity change. Native interpolated edge coordinates yield area and center. | Blur, neighboring contacts, uneven illumination and small openings displace the apparent boundary. |
| Pixel-integrated aperture model | Local intensity scale and background are nuisance variables. Shared blur, pixel integration, and nearby pattern contributions constrain widths and center. | Blur–CD trade-off, mismatch to EUV optical physics or insufficient signal. |
| Differential fit | Local linearization of the blurred aperture response permits small geometry and placement changes to be measured together. | Large displacement or CD change invalidates the linearization. Compare to the nonlinear model. |
| Integrated intensity | Flux is relatively stable under a normalized linear blur when the integration area contains the redistributed signal. A signed first moment estimates position. | Gain, phase contrast, leakage from neighbors and local background errors remain. Absolute open-area conversion needs independent bright/dark references. |
| Lattice harmonics | Relative amplitudes and a fitted contrast scale reduce gain dependence. Two non-collinear phases measure displacement. | Too few resolved diffraction orders, aliases, nonuniform pattern coverage or confounding with optical transfer. |
| Pooled aperture moments | Normalize brightness against each opening's local surround and core, assign fractional aperture occupancy, then pool areas, centers and within-opening second moments per tile. The compiled kernel supports throughput testing. | A blurred core changes the local intensity reference. Stress tests measure blur and sampling bias. Fixed reference sites and explicit aperture coverage matter in sparse or clipped regions. |

The flux-area concept has been experimentally applied to photomasks using independently measured clear and dark levels. Multiple-order optical CD measurements support evaluating sensitivity carried by different frequencies. Optical configurations in those papers differ from ACTIS. [Fiekowsky, optical flux-area measurement](https://aviphotomask.com/pdf/AVI_LinewidthMetrology_PMJ00.pdf) · [NIST multiple-order imaging](https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=912169)

## Interpreting precision

For an ideal bright-opening array with fixed pitch, an intensity integral can vary approximately with opening area. Taking its square root can halve relative scatter while preserving exactly the same underlying information. This motivates the independent size sweep and the dimensionless response comparison. Only a measured size sweep on real mask features can establish the relationship between physical CD and the actual detector observables. A matched, independently characterized set of holes spanning size, shape, pitch, orientation and field position would support evaluation of slope, absolute bias and residual dependence on sensor position. The SEM/AFM edge and axis convention must agree with the reported measurand. [NIST photomask linewidth uncertainty](https://www.nist.gov/publications/improving-uncertainty-photomask-linewidth-measurements)

The reported detector-position precision is dispersion across acquisitions of the same mask area. Hole-to-hole spread within an acquisition instead includes real local CD uniformity. Smoothing or jointly fitting the same hole's CD across repeats would reduce the first quantity artificially. Native-pixel metrology, fixed common sites and separate nuisance challenges protect the comparison. Subpixel correlation can recover fractional shifts, while absolute lattice indexing can remain undetermined on periodic data. [JCGM measurement precision](https://jcgm.bipm.org/vim/en/2.15.html) · [Guizar-Sicairos et al., subpixel registration](https://doi.org/10.1364/OL.33.000156)
